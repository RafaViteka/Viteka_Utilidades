# Fuente de tenencia de Málaga

Transcripción íntegra de las83 filas de «existencias minimas.xlsx» aportado por el usuario. Se conservan las columnas A–D y la fila de origen, sin metadatos personales del archivo. No se fusionan ATC repetidos.

SHA256 del XLSX original: 16fa6e6800f816f1ad4df57aa51ecaca2a06115c1ef25dc6efd006737375b8e0

Columna C es el mínimo transcrito; no se han corregido discrepancias del texto. La última fila indica2 en el nombre y4 en C: pendiente de confirmar. Los códigos adicionales de productos sanitarios no se tratan como ATC.

Generar catálogo con `python scripts/build-tenencia-catalog.py`.
