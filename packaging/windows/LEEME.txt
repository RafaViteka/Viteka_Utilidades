VITEKA UTILIDADES 0.9.2 - CANAL DE PRUEBAS

Instala sobre la version anterior. No hace falta desinstalar; las preferencias
se conservan en la carpeta local de tu usuario.

Inicio ofrece acceso al portal de soporte, AnyDesk, manuales, formacion, web
y contactos de Viteka. Las paginas se abren en tu navegador predeterminado.
AnyDesk abre el programa instalado en Program Files, sin conectarse a terceros
ni conceder acceso desatendido. Debes autorizar cada sesion.

El menu lateral se puede plegar y desplegar. Puedes elegir apariencia clara,
oscura o automatica. Ambos ajustes se conservan entre sesiones.

No hay utilidades de base de datos ni conexion a NixFarma. La interfaz Angular
esta incluida en el paquete. No necesitas iniciar un servidor para abrirla.
El instalador prepara Microsoft Edge WebView2 si falta: puede necesitar internet.
No requiere instalar Node ni el SDK .NET en el equipo del usuario.

Configuracion permite buscar, descargar, verificar e iniciar una actualizacion
de prueba desde GitHub, siempre con confirmacion. El instalador de Viteka aun
no dispone de firma digital del editor.

Este paquete no habilita acceso LAN ni instala automaticamente el servicio
opcional de desarrollo. Se mantiene la documentacion de ese servicio para una
fase posterior, sin alterar el DSN de NixFarma.

VENTANA Y ZOOM
Ctrl + rueda amplia o reduce el contenido. La rueda normal desplaza la pagina.
La barra superior muestra el porcentaje: botones menos/mas y 100 % para restablecer.
Ctrl + 0 tambien vuelve al 100 %. La preferencia se conserva entre sesiones.
Si un icono antiguo anclado no cambia, desanclalo y ancla de nuevo el acceso
Viteka Utilidades del menu Inicio despues de actualizar.
