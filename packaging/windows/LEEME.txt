VITEKA UTILIDADES - VISTA PREVIA LOCAL 0.7.0

Paquete Windows x64 autocontenido. No requiere instalar .NET en el puesto.

1. Inicia el servidor de demostración desde el menú Inicio; deja su ventana abierta.
2. Abre Viteka Utilidades desde el menú Inicio.
3. Puedes revisar el MVP visual. El catálogo está vacío y la configuración de NixFarma queda para una fase posterior.

El servidor solo acepta conexiones del mismo equipo. Este paquete no conecta
con Oracle, no instala un servicio de Windows ni permite usar el servidor desde
otros puestos. El despliegue real necesita TLS, configuración de red y ODBC.

No contiene credenciales, registros de puestos ni datos reales de farmacia.
Preferencias y credenciales se guardan fuera del directorio de instalación.
La desinstalación conserva esos datos locales; revoca las autorizaciones por
separado cuando corresponda.

Este canal de pruebas permite buscar, descargar y verificar un instalador de
GitHub y ejecutarlo con confirmacion. La version actual debe instalarse una
vez manualmente para incorporar el actualizador. Para entregar a farmacias
sigue pendiente la firma de codigo y la validacion del despliegue completo.
Este instalador de evaluación puede no estar firmado digitalmente.

Compatibilidad requerida: Windows 10/11 y Server 2022/2025. Validar la edición,
versión, parches y arquitectura concretos; no se ha certificado toda esa matriz.

SERVICIO OPCIONAL DE VISTA PREVIA
El servidor admite --service. El paquete incluye Servidor/manage-service.ps1
para administrarlo con permisos elevados. Consultar docs/servicio-windows.md
antes de instalarlo. El instalador no lo registra automaticamente.

INTERFAZ ANGULAR + WEBVIEW2
La interfaz se incluye localmente y no necesita iniciar el servidor.
El instalador prepara Microsoft Edge WebView2 si falta (puede necesitar internet).
Se conserva la instalacion anterior y las preferencias del usuario.
