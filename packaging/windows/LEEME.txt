VITEKA UTILIDADES 0.12.3 - CANAL DE PRUEBAS

INSTALACION
Instalar o actualizar en el servidor de NixFarma, sobre la version anterior.
No hace falta desinstalar. El paquete incluye .NET; WebView2 se prepara si falta.
El instalador registra VitekaUtilidadesAccess como servicio de Windows bajo
LocalService y prepara su identidad HTTPS. No se modifica el DSN ni Oracle.

USUARIOS DE LA FARMACIA
Las cuentas son compartidas por el servidor y los puestos. Solo al crear el
registro por primera vez se preparan estas credenciales iniciales:
  Viteka     / jupiter : superadministrador, incluida Configuracion tecnica.
  F. titular / 1234    : administrador, todo salvo Configuracion tecnica.
  usuario    / 0000    : Inicio y aplicaciones que tenga autorizadas.
Se exige cambiar la contrasena inicial, con un minimo de 3 caracteres.
Los usuarios solo cambian su contrasena. El titular crea y gestiona usuarios
normales. Viteka gestiona todos los roles. Los cambios revocan sesiones previas.
Los puestos seguiran bloqueados mientras haya cuentas activas con la contrasena
inicial de instalacion. Cambiarlas o restablecerlas desde el servidor primero.
No se restauran las contrasenas iniciales al actualizar ni ante un registro danado.

CONFIGURACION Y CONEXION ORACLE
Configuracion agrupa Mi cuenta para todos, Usuarios para titular/Viteka y
conexion tecnica solo para Viteka. La conexion previa del usuario Windows
original se migra al servicio al entrar Viteka en ese mismo servidor.
Probar la conexion despues de actualizar: LocalService debe poder utilizar
el DSN de sistema Oracle de 64 bits y resolver su TNS. La prueba es solo lectura.
Las credenciales se protegen en el servidor; no se copian a los puestos.
El catalogo de aplicaciones sigue vacio hasta incorporar las primeras utilidades.

PUESTOS
Distribuir Cliente completo con access-server.json y access-root.cer en un
compartido con lectura/ejecucion para usuarios y escritura solo para mantenimiento.
Abrir ese cliente desde los puestos; no instalar el servidor en cada puesto.
No copiar datos de ProgramData ni claves privadas. El cliente verifica la identidad
HTTPS del servidor. El puerto 7447 solo se habilita para red local Privada/Dominio.
Las preferencias de cada cuenta se conservan localmente, separadas entre usuarios.

ACTUALIZACIONES
Actualizaciones se encuentra dentro de Configuracion. Busca cada 24 horas
con la app abierta o al siguiente arranque si queda pendiente. Mantiene el boton
Buscar actualizaciones, el aviso y un historial de publicaciones y ejecuciones.
Solo titular/Viteka y desde el servidor pueden iniciar el instalador, con confirmacion.
Antes de actualizar, cerrar Viteka en los puestos que usan archivos compartidos.
Se reinicia el servicio, conservando cuentas y credenciales; los puestos vuelven a entrar.
Las descargas conservan verificacion de HTTPS, destinos, tamano y SHA256.
El instalador todavia no tiene firma digital del editor: es un canal de pruebas.

VENTANA Y ZOOM
El menu se puede plegar manualmente. Mi cuenta contiene contrasena y apariencia.
Ctrl + rueda o Ctrl +/- cambia la escala; Ctrl + 0 vuelve al 100 %.
La barra superior muestra el porcentaje y controles de zoom.
